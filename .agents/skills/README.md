# Skills

Project-specific conventions, standards, and patterns.

Add a markdown file per concern. Examples:

| File | Purpose |
|---|---|
| `go.md` | Go conventions, error handling, project structure |
| `terraform.md` | Module patterns, naming conventions, state management |
| `nextjs.md` | Next.js conventions, middleware patterns, component structure |
| `react-native.md` | React Native conventions, navigation patterns |
| `testing.md` | Testing standards, coverage expectations, patterns |
| `git.md` | Commit conventions, branch naming, PR process |

Personal skills (communication style, experience level preferences) belong in
~/.claude/CLAUDE.md — not here. Skills here are team standards for this project.
